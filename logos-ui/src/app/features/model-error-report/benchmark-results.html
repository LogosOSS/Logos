When settings change

Logos measures the current settings first, then tests each trial on the same requests at the same load. It adopts the fastest trial that passes all checks and beats that night’s baseline.

What does Logos check?
  • Every request must finish successfully in the same environment and with the same finish reason as its baseline.
  • Each answer must stay within 20% of its baseline output token count.
  • The time to finish 95% of requests (p95) can rise by at most 10%.

Small gains can still reflect normal variation between runs. If no trial qualifies, Logos keeps the current settings. See Currently deployed for the confirmed configuration.
